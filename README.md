# DragynClient

A custom launcher for Minecraft: Java Edition 1.21.11 (Fabric).

- Sign in securely with your Microsoft account (official Microsoft login)
- Install and manage Fabric mods from Modrinth
- Separate game profiles, each with its own mods, worlds and settings
- Performance-focused: Sodium + Polydium (Vulkan) included

DragynClient is a fan-made project and is not affiliated with Mojang or Microsoft.
Players must own Minecraft: Java Edition to play.
